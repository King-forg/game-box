# game-box

## A box full of games all coded using the base python functions!

You heard me right! That means:
 - No more pip install
 - No internet needed
 - No commands needed (Except initial startup)

 Includes:
  - Higher or Lower (95% Human coded)
  - Naughts and crosses (About 50% human coded but the other 50% is the bot prediction code which I couldnt be bothered to do)
  - 21 (Nim) (100% Human coded)
  - Blackjack (~80% human coded (most was just debugging))
  - Connect 4 (~75% human coded (Most was for repetitive tasks like wintesting and bots))
  - Rock Paper Scissors (99.9% human coded)
  - Bordle (Wordle clone) (~90% human coded; the word lists were generated with AI help)

Bordle requires both txt files to work, however you may edit them with new words.

Sometimes I just cant fix bugs so I use the copilot to debug them. (Dont worry moderators all of the ai coding time was recorded accordingly)
